# コード生成計画 - ユニット2拡張: 高度なタイポグラフィとスクリプトサポート

本計画は、Shaping EngineにおけるGPOSルックアップタイプ3（Cursive Attachment/草書体アタッチメント）およびGPOSルックアップタイプ8（Chained Contextual Positioning/連鎖文脈位置調整）の実装範囲をカバーします。これにより、Pure ZigによるShaping Engineの「高度なタイポグラフィ」機能が完了します。

## ユニットの文脈

- **対象ユニット**: Shaping Engine (Unit 2 Extension)
- **主要ストーリー**: US-3 - カーニングと合字のサポート（筆記体アタッチメントおよび連鎖文脈位置調整の追加）
- **依存関係**: Unit 1 `Face`、Unit 2 基本レイアウト、`src/ot_layout.zig`内の`Coverage`および`ClassDef`モジュール
- **実装対象ファイル**:
  - `src/gpos.zig`

## 実行チェックリスト

### GPOSルックアップタイプ3: Cursive Attachment（草書体アタッチメント）
- [ ] ステップ 1: 草書体アタッチメントのテーブルフォーマットと型の定義
  - `EntryAnchor`および`ExitAnchor`のパース構造体を定義する。
  - GPOSタイプ3草書体アタッチメントサブテーブル（Format 1）のフォーマットとオフセットを定義する。
  - `GposLookupType`列挙型に`cursive_attachment = 3`を追加する。

- [ ] ステップ 2: 草書体アタッチメントの位置調整ロジックの実装
  - `src/gpos.zig`に`applyCursiveAttachment`を実装する。
  - シェイプされたグリフストリームをトラバースし、隣接するグリフ間でエントリーアンカーとエグジットアンカーを関連付ける。
  - 草書体の配置要件（現在のグリフのEntryAnchorを直前のグリフのExitAnchorと合わせる）に従って、`ShapedGlyph`ストリームの`x_offset`、`y_offset`、`x_advance`、`y_advance`プロパティを正しく調整する。

- [ ] ステップ 3: 草書体アタッチメントの単体テストの追加
  - 擬似的な草書体アンカーテーブルを使用したテストを追加する。
  - 水平方向および垂直方向のオフセット調整を検証する。

### GPOSルックアップタイプ8: Chained Contextual Positioning（連鎖文脈位置調整）
- [ ] ステップ 4: 連鎖文脈位置調整のフォーマットと型の定義
  - `GposLookupType`列挙型に`chained_contextual_positioning = 8`を追加する。
  - 連鎖文脈Format 3（カバレッジベース）の位置調整構造体とフォーマットを定義する。
  - 連鎖文脈Format 1（グリフベース）およびFormat 2（クラスベース）のフォーマットを定義する。

- [ ] ステップ 5: 連鎖文脈位置調整のシーケンス一致判定の実装
  - `gsub_chained_contextual.zig`のデザインパターンを再利用し、backtrack、input、lookaheadのカバレッジ/クラスシーケンスの一致ロジックを実装する。
  - 一致判定ヘルパーをクリーンかつ境界チェックが有効な形で維持する。

- [ ] ステップ 6: 再帰的なルックアップ適用の実装
  - サブ位置調整ルックアップを実行する`applyChainedContextualPositioning`を実装する。
  - 再帰呼び出しがGPOSの再帰上限（`max_recursion_depth = 16`）によって制限されるようにする。
  - 入れ子になった位置調整の変更が、対象グリフのオフセットとアドバンスに正しく反映されることを検証する。

- [ ] ステップ 7: 連鎖文脈位置調整の単体テストの追加
  - Format 3 カバレッジベースの連鎖文脈位置調整의テストを追加する。
  - 再帰深度制限の回帰テストを追加する。

### 堅牢化と統合
- [ ] ステップ 8: GPOSルックアップディスパッチャーの更新
  - `applyLookupSubtable`でGPOSルックアップタイプ3と8をマッピングする。
  - 拡張位置調整（タイプ9）が、入れ子になったタイプ3およびタイプ8テーブルへ再帰的に適切にディスパッチされることを保証する。

- [ ] ステップ 9: 検証スイートの実行
  - 既存のすべてのシェイピングテスト（カーニング、マークアタッチメント、合字、RTL、Indic並べ替えを含む）が通過することを確認する。
  - `zig build test`を実行する。
  - CLIビルドとSVGレンダリングの動作検証テストを行う。
