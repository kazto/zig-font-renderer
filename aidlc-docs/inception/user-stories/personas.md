# Personas

## 1. 開発者：ケンジ (Library Integrator)
- **役割**: ゲーム開発者。
- **目的**: 自分のカスタムゲームエンジンにフォントレンダリング機能を組み込みたい。
- **モチベーション**: 
  - 外部のCライブラリ（FreeType等）をリンクしたくない。
  - 静的リンクが可能で、メモリ管理が明快なPure Zig実装を求めている。
  - パフォーマンス（リアルタイム性）が重要。
- **ニーズ**:
  - 使いやすい高レベルAPI（「テキストを表示する」）。
  - 必要に応じて内部データにアクセスできる低レベルAPI。

## 2. CLIユーザー：ユミ (CLI Tool User)
- **役割**: Webデザイナー / 技術系ブロガー。
- **目的**: テキストをアウトライン化（SVG）して、ロゴや特殊なフォントの装飾として使いたい。
- **モチベーション**:
  - フォントを埋め込まずに、パスデータとしてSVGを生成したい。
  - シンプルで堅牢なCLIツールが欲しい。
- **ニーズ**:
  - シンプルなコマンドライン引数。
  - 成功時に余計な出力をしないUnix哲学に則った挙動。
  - 正確な日本語・ラテン文字のレンダリング。
